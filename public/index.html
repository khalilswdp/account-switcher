Account Profiles

Two persistent Chromium profiles, no proxies. Log in once with "Login / Sync Session" (a visible window on this machine), then click "Save Session". After that the profile stays signed in, so there is nothing to reconnect and no MFA again until the site expires the session.

From the Vault

Pick an account that exists in the Vault, then load one part of it onto this Mac and switch to it: Desktop quits and reopens the Claude app on it, CLI opens Terminal as it, Browser signs its profile in. A new account gets its folders created (CLI config: ~/.claude for main, ~/.claude-<name> for the others).

Activity

Back up

One encrypted file with the account's three logins and what cannot be re-downloaded: Claude Code history, settings, skills and plugins, and the desktop app's data. Without the passphrase the file cannot be opened, and there is no way to recover it. Store the file somewhere other than this Mac's disk.

Existing backups

Restore from a backup

Opens a backup file and puts back what you choose. It only adds what is missing: nothing that already exists is overwritten or deleted.

The newest backup in the folder is selected for you.
