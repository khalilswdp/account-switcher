Claude accounts

Switch the Claude app and Claude Code between your accounts without signing in again. Each login can be saved to your private Vault, so another computer, Mac or PC, can load it.

One-time setup: which account is the Claude app signed in as right now?

Open the Claude app and look at its account, then pick it here. Nothing is moved or changed; from then on the dashboard can switch the app between accounts.

In the Vault, not on this computer yet

"Add to this computer" gives the account a card here. Its "Load from Vault" buttons then bring each login onto this computer.

No accounts on this computer yet

Use "Add an account…" above, or "Add to this computer" on an account from the Vault.

Activity

How this works
  • Claude app: each account has its own app data on this computer. Switching quits the app, swaps which data it uses, and reopens it. Nothing is copied or deleted.
  • Claude Code: each account has its own Claude Code folder and login on this computer. "Open in Terminal" starts Claude Code as that account.
  • Vault: "Save to Vault" puts one login in your private Vault; "Load from Vault" brings that same account's login back onto this computer. No account can load another account's login.
  • Protected accounts (PROTECTED_ACCOUNTS in .env, "main" by default): switched to, saved and backed up like any other, but never removed from this computer, and nothing of theirs can be deleted here.
  • Backup: one encrypted file with the account's two logins and what cannot be re-downloaded (Claude Code history, settings, the app's data). Restoring only adds what is missing.

Also delete, permanently:

Require a passphrase for deletions

Every deletion of data from this page will ask for it. Only a hash is stored, next to the Vault keys. To stop requiring one, delete the file delete-passphrase in ~/.claude-switcher-vault.

Back up

One encrypted file with the account's two logins and what cannot be re-downloaded: Claude Code history, settings, skills and plugins, and the Claude app's data. Without the passphrase the file cannot be opened, and there is no way to recover it. Store the file somewhere other than this computer's disk.

Existing backups

Restore from a backup

Opens a backup file and puts back what you choose. It only adds what is missing: nothing that already exists is overwritten or deleted.

The newest backup in the folder is selected for you.
